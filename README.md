# FASTLANE

App per la programmazione degli allenamenti di nuoto master: sedute, corsie, tecnica, virate e partenze.

- App: https://pietrocirillo.github.io/fastlane/
- Accesso riservato con Google (solo gli indirizzi in `config.js`); dati su Firebase Firestore protetti da `firestore.rules`.
- Funziona anche offline e si installa sul telefono («Aggiungi a Home»).
